# 🐍 ParceSnake 🇨🇴

**ParceSnake** es una versión del clásico juego Snake desarrollada en **Java** aplicando los principios de la **Programación Orientada a Objetos (POO)**.

Este proyecto no solo recrea la mecánica tradicional del juego, sino que también incorpora una identidad visual inspirada en Colombia 🇨🇴, haciendo uso de los colores de la bandera y una experiencia más cercana y personalizada para el usuario.

---

## 🎮 Características principales

* 🐍 Movimiento clásico de Snake
* 🍎 Sistema de crecimiento al consumir comida
* 💀 Detección de colisiones (paredes y cuerpo)
* 🔄 Reinicio del juego con teclas **R** o **ENTER**
* 🇨🇴 Diseño inspirado en la bandera de Colombia:

  * Cabeza amarilla 🟡
  * Cuerpo con patrón repetitivo amarillo, azul y rojo
* 🧮 Sistema de puntaje dinámico
* 🎨 Interfaz mejorada con mensajes visuales

---

## 🧠 Conceptos aplicados

Este proyecto fue desarrollado aplicando:

* Programación Orientada a Objetos (POO)
* Uso de clases y objetos
* Encapsulamiento
* Manejo de eventos (teclado)
* Estructuras dinámicas (`ArrayList`)
* Lógica de colisiones
* Ciclo de juego con `Timer`


## 🚀 Versiones del proyecto

### 🔹 Versión Base

Implementación original del juego Snake con funcionalidad básica.

### 🔹 Versión Mejorada

Incluye mejoras como:

* Rediseño visual
